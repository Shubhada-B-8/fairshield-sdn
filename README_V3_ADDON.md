# FairShield V3 AI/5G add-on

This add-on preserves the existing V1 and V2 code. It adds an independently runnable
V3 experiment script and two modules:

- `v3_ai.py`: Random Forest traffic-risk classifier trained on labelled samples
  generated by the existing FairShield simulator.
- `v3_simulator.py`: AI-assisted admission control, weighted max-min allocation,
  and 5G-style QoS telemetry proxies.
- `scripts/run_v3_demo.py`: command-line runner that writes CSV and JSON outputs.

## Important scope

This is the first runnable V3 simulation milestone, not a completed live 5G deployment.
The AI model is trained on synthetic samples generated by the existing simulator.
Latency, jitter, packet loss, connection reliability and utilization in this version
are simulated proxies. It does not yet read real gNB/UE radio telemetry, RSRP, RSRQ,
SINR, PRB utilization, handover events, or control an Open5GS/UERANSIM deployment.

## Install

From the existing FairShield-SDN-V2.0.0 repository root, copy the add-on files
into the matching paths, then run:

```bash
python -m pip install -e ".[ml]"
```

If your shell does not support the quotes in the same way, use:
```bash
python -m pip install -e .[ml]
```

## Run

One DDoS experiment:
```bash
python scripts/run_v3_demo.py --scenario ddos --windows 30 --seed 7 --capacity 500 --out outputs_v3_ddos
```

All scenarios:
```bash
python scripts/run_v3_demo.py --scenario all --windows 30 --seed 7 --capacity 500 --out outputs_v3
```

Mixed traffic:
```bash
python scripts/run_v3_demo.py --scenario mixed --windows 30 --seed 7 --capacity 500 --out outputs_v3_mixed
```

Outputs:
- `v3_summary.csv`
- `v3_summary.json`
- `v3_trace.csv`

Run the tests after copying:
```bash
python -m pip install -e ".[ml]"
python -m unittest tests.test_v3_ai -v
```

## Windows PowerShell setup

```powershell
cd "$HOME\projects\fairshield_sdn\FairShield-SDN-V2.0.0"
conda activate fairshield
python -m pip install -e ".[ml]"
python scripts/run_v3_demo.py --scenario all --windows 30 --seed 7 --capacity 500 --out outputs_v3
```

If you use a different environment name, activate the environment in which the
existing FairShield project runs.

## Current decision policy

- Train a Random Forest classifier from the existing simulator's labelled synthetic flows.
- Predict attack probability for each source.
- If AI risk is at least 0.50, cap that source at 5 PPS.
- Otherwise preserve offered demand.
- Apply the existing weighted max-min allocator under the configured link capacity.
- Calculate simulated latency, jitter, packet-loss and connection-reliability proxies.

The 0.50 AI threshold and 5 PPS cap are initial experimental defaults, not optimized
or validated 5G operating thresholds. They must be evaluated and tuned.

## Next engineering milestone

Replace simulated QoS proxies with timestamp-aligned measurements from a 5G testbed.
Candidate telemetry includes one-way/RTT latency, throughput, jitter, packet loss,
connection setup/drop rates, handover success/interruption, RSRP, RSRQ, SINR and PRB
utilization. Real 5G control requires supported RAN/core interfaces; OpenFlow alone
does not configure radio-layer parameters.
